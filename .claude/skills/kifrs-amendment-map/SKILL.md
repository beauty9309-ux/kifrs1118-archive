# A 개정 지도 (전체 1장) 생성

## 목적
빽빽한 마스터 신구대조 문서를 **한 화면 '내가 신경 쓸 게 뭔지'** 로 소화한다. 40개를 페이지로 쪼개지 않는다. 이 한 장이 곧 /amendments 인덱스다.

## 소스
- **`sources/1118-consequential-amendments.txt` 하나뿐.** 다른 소스 불필요.

## 절차
1. 마스터에서 개정 대상 기준서 목록을 추출("기업회계기준서 제1XXX호 ‘…’" 헤더 기준).
2. 각 기준서를 영향도로 분류:
   - **경미:** "※ 영향 없음 / 개정할 사항 없음" 주석이 있거나, 용어(IFRSs→IFRS Accounting Standards)·참조(제1001호→제1118호)·명칭(제1008호→'재무제표의 작성 기준') 정비뿐인 경우.
   - **실질:** 표시·측정·공시 로직이 바뀐 경우(예: 제1007호 문단 10이 1118호 문단 9~43·113~114를 적용하도록 변경). 분량이 크고 개정 문단이 많은 섹션이 후보.
   - 애매하면 '확인 필요'로 두고 지어내지 않는다.
3. 표 구성: `기준서 | 바뀐 문단 | 영향도 | 한 줄 요지 | 링크`.
   - 실질 행 → `kifrs-amendment-page`로 만든 상세 페이지로 링크.
   - 경미 행 → 링크 없이 표에서 요지만(별도 페이지 없음).
4. 상단 개요 한 문단: "1118호는 약 N개 기준서를 개정했고, 대부분은 용어·참조 정합(안심), 실질 영향은 소수(현금흐름표 등)에 집중."
5. `shared.css` 링크, 홈/콘텐츠와 같은 디자인 언어. 표는 실질=강조(색), 경미=차분(회색).
6. `node check-copyright.js` 통과.

## 페이지 구조
헤더 → eyebrow(개정 지도)+H1+개요 한 문단 → **영향도 요약**(경미 N건·실질 N건) → **영향도 표**(위 5열, 실질 먼저) → 시행 안내(1118호 적용 시점) → 출처·저작권·면책.

## 출력
- `amendments-map.html` (= /amendments 인덱스 겸용). 새 실질 상세 페이지가 생기면 표의 해당 행 링크만 갱신.

## 저작권
- 기준서 문단 전문 복제 금지 — 번호 + 한 줄 요지 + 회계기준원 링크. 표의 '요지'는 자기 표현으로.
