# A 개정 지도 페이지 생성

## 언제 쓰나
회계기준원 기준서 원문에서 "제1118호 제정에 따른 개정"을 찾아, 그 기준서의 개정 지도 페이지를 만들 때.

## 필요한 입력
- 대상 기준서의 회계기준원 원문(업로드 PDF/텍스트). **없으면 먼저 요청한다. 내용을 기억으로 추측하지 않는다.**

## 절차
1. **개정 근거 찾기.** 원문에서 `1118` 을 검색해 "2025년 12월 공표한 제1118호에 따라 문단 N을 개정하였다" 형태의 개정 근거 문단(보통 부칙 C1x)을 찾는다.
2. **개정 대상·성격 확인.** 실제로 바뀐 문단 N의 본문을 원문에서 읽고, 변경이 (a) 실질 개정인지 (b) 참조·명칭 정비인지 판정한다.
3. **영향도 판정.** `낮음`(참조·명칭 정비) / `중간`(표시·공시 일부 변경) / `높음`(수익·측정·표시 로직 변경). 근거를 함께 기록.
4. **템플릿 채우기.** 기준 파일 `kifrs1118-amendment-1115.html` 을 복제해 내용만 교체한다. CSS·구조는 그대로 둔다.
5. **자가 점검.** 문단 전문 복제 없음 / 근거 문단·회계기준원 링크 포함 / 반응형·접근성 / 하단 고지.

## 페이지 구조 (순서 고정)
1. 헤더 + breadcrumb(`개정 지도 > 제[번호]호`)
2. eyebrow(`개정 지도 · 1118호 연쇄개정`) + H1 + dek(**결론 먼저**) + 출처 태그(+회계기준원 링크)
3. **개정 영향도 배너** — 낮음/중간/높음 스케일 + 한 줄 결론
4. `무엇이 바뀌었나` — 개정 대상 문단 + `변경 전 → 변경 후`(짧게)
5. `왜 바뀌었나` — 1118호 패키지와의 연결
6. `실무 시사점` — 체크리스트(무엇이 그대로인지 / 무엇만 손대면 되는지)
7. `시행` — 1118호 적용 시점(2027.1.1 이후 최초 회계연도, 조기적용 가능)
8. `근거 문단` — 문단번호 + 자기표현 요지 + 회계기준원 링크
9. 출처·저작권·면책 고지

## 저작권 (필수)
- 기준서 문단 **전문 복제 금지**. 번호 + 요지만.
- 제목·명칭 변경(예: 제1008호 → '재무제표의 작성 기준')은 이름이므로 그대로 표기 가능.
- 원문은 모두 `https://www.kasb.or.kr/` 로 링크.

## 출력
- `/amendments/k[번호].html` (예: `k1007.html`). 정적 단계에서는 파일명 `kifrs1118-amendment-[번호].html`.
- 완료 후 홈(`kifrs1118-home.html`)의 `최근 업데이트` 피드에 항목 1줄 추가.

## SEO

- JSON-LD `Article` + `BreadcrumbList`, `canonical`, `lang="ko"`.
