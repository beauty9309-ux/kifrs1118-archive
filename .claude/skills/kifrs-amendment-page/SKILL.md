# A 개정 상세 페이지 생성 (실질 개정 소수만)

## 언제 쓰나 / 쓰지 않나
- **쓴다:** 영향도가 '중간/높음'인 실질 개정(표시·측정·공시 로직 변경). 예상 후보: 제1007호 현금흐름표, 제1034호 중간재무보고, 제1033호 주당이익, 제1012호 법인세, 제1105호 매각예정·중단영업.
- **쓰지 않는다:** 용어(IFRSs→IFRS Accounting Standards)·참조(제1001호→제1118호)·명칭 정비 등 경미 개정. → 별도 페이지 대신 `kifrs-amendment-map`의 표에 한 행으로 둔다.

## 소스
- **1차: `sources/1118-consequential-amendments.txt`** 에서 해당 기준서 섹션(예: "기업회계기준서 제1007호")을 찾는다. (기준서 원문을 하나씩 뒤지지 말 것 — 이 문서가 전체 신구대조본)
- **보조(선택): `sources/standards/`** 의 해당 기준서 원문 PDF — 바뀐 문단의 맥락 확인용.
- 소스가 없으면 먼저 요청한다. 내용을 기억으로 추측하지 않는다.

## 절차
1. 마스터 문서에서 해당 기준서 섹션을 찾고, 섹션 끝의 **개정 근거 문단**(예: "…제1118호에 따라 문단 X를 개정하였다")에서 바뀐 문단 번호를 전부 뽑는다. 이 문단 번호를 출처로 기록.
2. 마스터의 **신구대조 병기**(앞=신/뒤=구)로 문단별 변경 내용을 읽는다.
3. 문단별 판정:
   - 무엇이 왜 바뀌었는지 마스터에서 명확하면 → 확정.
   - 마스터만으로 불분명하면 → '변경 전/후: 회계기준원 대조본 확인 필요'로 표시하고 **지어내지 마**.
   - 실질(인식·측정·표시 변경) vs 참조·용어 정합을 구분.
4. 영향도(중간/높음) 판정.
5. 기준 파일 `kifrs1118-amendment-1115.html` 복제 → 본문만 교체(`shared.css` 링크 유지).
6. `node check-copyright.js <파일>` 통과 + 모바일·링크 확인.
7. 개정 지도(`kifrs-amendment-map` 산출물)의 해당 행을 이 상세 페이지로 링크 + 홈 피드에 1줄 추가.

## 페이지 구조 (순서 고정)
헤더+breadcrumb → eyebrow+H1+dek(결론 먼저)+출처 → 개정 영향도 배너(낮음/중간/높음) → 무엇이 바뀌었나(변경 전→후) → 왜 바뀌었나(1118호와의 연결) → 실무 시사점 → 시행(1118호 적용 시점, 2027.1.1 이후, 조기적용 가능) → 근거 문단 → 출처·저작권·면책.

## 저작권
- 번호 문단 본문은 요지 위주로 인용(원문은 회계기준원 링크). BC·적용사례·소수의견은 **요약만**.
- 마스터 문서는 신구대조라 요약·인용 근거로 적합하나, 전문 복붙은 금지.
