# A 개정 지도 페이지 생성

## 언제 쓰나
회계기준원 기준서 원문에서 "제1118호 제정에 따른 개정"을 찾아, 그 기준서의 개정 지도 페이지를 만들 때.

## 필요한 입력
- 대상 기준서의 회계기준원 원문(업로드 PDF/텍스트). **없으면 먼저 요청한다. 내용을 기억으로 추측하지 않는다.**

## 절차
1. **1118 전수 검색 → 개정 대상 문단 전체 추출.** 원문 전체에서 `1118` 을 검색한다. 특히 문서 맨 뒤 "시행일과 경과규정" 부칙에서 개정 근거 문단(예: 문단 66, C1x 등)을 찾아, 그 문단이 지목하는 "1118호에 따라 개정된 문단 번호"를 전부 뽑는다 — 한 개일 수도, 여러 개일 수도 있다. 이 부칙 문단 번호를 **개정 근거 출처**로 기록한다.
2. **문단별 판정(문단마다 반드시 개별 확인).** 1에서 뽑은 개정 대상 문단 각각의 본문을 실제로 읽고 판정한다.
   - 본문이 **'제1118호'를 직접 인용**하면 → **참조 갱신으로 확정**.
   - 인용이 없거나, 무엇이 바뀌었는지 본문만으로 알 수 없으면 → **"변경 전/후: 회계기준원 대조본 확인 필요"** 로 명시한다. 이전 문구를 절대 지어내지 않는다 — 확보한 원문이 개정 후 문구만 수록한 조기적용 가능본일 수 있고, 대조본이 없으면 특정할 수 없다.
   - 각 문단이 **실질 개정**(인식·측정 변경)인지 **참조·표시·용어 정합**인지 구분해 기록한다.
3. **영향도 판정.** 2의 문단별 판정을 종합한다. 전부 참조·표시·용어 정합이면 `낮음`, 표시·공시 일부만 변경되면 `중간`, 수익·측정·표시 로직 변경이 포함되면 `높음`. 판정 근거(어느 문단이 왜 그렇게 분류됐는지)를 함께 기록한다.
4. **템플릿 채우기.** 기준 파일 `kifrs1118-amendment-1115.html`(위치: `amendments/k1115.html`)을 복제해 본문만 교체한다. `shared.css` 링크(`/shared.css`)와 구조는 그대로 둔다.
5. **BC·적용사례·소수의견은 요약만.** 결론도출근거(BC), 적용사례, 소수의견 등 부속 자료는 저작권상 요약만 인용한다. 개정 대상 문단 본문도 전문이 아닌 요지 위주로 쓰고, 원문은 회계기준원 링크로 연결한다.
6. **자가 점검.** `node check-copyright.js <파일>` 통과 / 근거 문단·회계기준원 링크 포함 / 반응형·접근성 / 하단 고지.

### 문단 판정 표기 규칙
- **참조 갱신 확정**: `.diff` 블록에 개정 후(현재) 문구를 표기. 개정 전 문구까지 원문에서 확인되면 `변경 전 → 변경 후`로, 확인되지 않으면 "개정 후(현재)"만 표기하고 "이전 문구는 대조본 없이 특정 불가"를 명시한다.
- **대조본 확인 필요**: `.diff` 블록의 라벨을 "확인 가능 여부"로 바꾸고 "원문 문단 본문에는 1118(또는 관련 근거) 언급 없음" 등 사실만 적는다. 추측성 서술 금지.
- 두 경우 모두 `실무 시사점`에 "사내 문서·매뉴얼은 회계기준원 원문으로 재확인 권장" 항목을 넣어, 확인 필요 상태를 독자에게 투명하게 알린다.

## 페이지 구조 (순서 고정)
1. 헤더 + breadcrumb(`개정 지도 > 제[번호]호`)
2. eyebrow(`개정 지도 · 1118호 연쇄개정`) + H1 + dek(**결론 먼저**) + 출처 태그(+회계기준원 링크)
3. **개정 영향도 배너** — 낮음/중간/높음 스케일 + 한 줄 결론
4. `무엇이 바뀌었나` — 개정 대상 문단 + `변경 전 → 변경 후`(짧게)
5. `왜 바뀌었나` — 1118호 패키지와의 연결
6. `실무 시사점` — 체크리스트(무엇이 그대로인지 / 무엇만 손대면 되는지)
7. `시행` — 1118호 적용 시점(2027.1.1 이후 최초 회계연도, 조기적용 가능)
8. `근거 문단` — 문단번호 + 자기표현 요지 + 회계기준원 링크
9. 출처·저작권·면책 고지

## 저작권 (필수)
- 기준서 문단 **전문 복제 금지**. 번호 + 요지만.
- 제목·명칭 변경(예: 제1008호 → '재무제표의 작성 기준')은 이름이므로 그대로 표기 가능.
- 원문은 모두 `https://www.kasb.or.kr/` 로 링크.

## 출력
- `amendments/k[번호].html` (예: `k1007.html`).
- 완료 후 홈(`kifrs1118-home.html`)의 `최근 업데이트` 피드에 항목 1줄 추가.
- 개정 지도 인덱스 페이지(`amendments-index.html`)가 존재하면 그곳에도 1줄 추가. 아직 없으면 건너뛰고 사용자에게 알린다.
